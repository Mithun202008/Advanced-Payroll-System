P157 (align=JUSTIFY (3)): RiskLens is an educational ATM and digital-banking security simulator developed using Core Java 21 and the Java Standard Library. The system extends a conventional banking application with secure authentication, behavioral profiling, weighted rule-based fraud detection, explainable risk scoring, automated security decisions, concurrent event monitoring and tamper-evident audit logging. Each transaction is evaluated using contextual signals such as transaction amount, velocity, time, terminal history, authentication failures, daily limits, recent PIN changes and cross-channel activity. The resulting risk score is mapped to security decisions such as ALLOW, CHALLENGE, MONITOR and FREEZE, while the contributing reasons are retained for explain-ability. Controlled demonstrations produced risk levels ranging from 0 to 115, including a documented 115-point account-freeze scenario. The project demonstrates how object-oriented programming, Java concurrency, collections, cryptography, file handling and design patterns can be integrated into a cyber-security oriented banking application. | F=set() S={14.0} B={None} C={'None'}
